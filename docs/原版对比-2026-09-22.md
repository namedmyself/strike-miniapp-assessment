## 三、被删掉的 60 + 14 + 3 + … 行，逐条是什么

这是"有没有动到本来能用的东西"的关键。**所有删除行都属于「替换掉一段本身是坏的实现」**，没有一条是删掉好代码：

### 1. 三处"坏的实现"被替换（这是最该改的）

| 原版实现 | 问题 | 证据 |
|---|---|---|
| `runtime_session.current_route()`（15 行单点取值：`window.__as` / `globalThis.__wxRoute`，读不到就 `return ""`） | **静默返回空串**，调用方分不清"路由为空"和"读失败"；且 `__wxRoute` 在 page-frame 里**根本不存在** | 现场对照实测：旧表达式返回 `""`，新降级链返回 `"pages/other/tzs/collect"` |
| `get_basic_page_info` 里的 `route: globalThis.__wxRoute \|\| ''` | 同上，`snapshot.route` **必然**为空；且 `__wxRoute` 的值还是**陈旧**的（实测它给 `tzs/success`，真实是 `tzs/collect`） | 同上 |
| `scan_sensitive_storage`（返回 `"raw": raw_results`，`findings` 判空） | **假阴性**：工具报 `findings: []`，而真实密钥就在它自己返回的 `raw` 里 | 实测原始返回体 `findings:[]` + 二次核查用真实数据重跑旧算法仍为 0 |

### 2. 其余删除行

- `local_app.py` 的一行式 `return await session.xxx(...)` → 换成多行：**因为新增了参数**（`compact` / `excludeTelemetry` / `maxLength` / `includeRaw` / `maxRawChars`），单行装不下。属签名驱动的连带重排，非人为美化。
- `local_app.py` 的 `"error": str(exc)` → 换成 `str(exc).strip() or repr(exc).strip() or exc.__class__.__name__`。因为**某些异常 `str(exc)` 是空串**，会返回 `error:""` 却提示"真实原因见 error 字段"。
- `cdp_client.py` 的 `if self.is_connected() and self.ws_url == target:` → 加入 `pendingCalls > 0` 判定；`_close_locked(fail_pending=False)` → `True`。都是 N-2 的修复点。
- `nav_inject.js` 3 行：`normalizeRoute(item.pagePath)` / `indexOf(page.route)` / `resolve({ok:true,...})` → 换成 `stripHtmlExt(...)` 与带 `routeBefore` 的版本。N-1 + P1-3。
- `mcp_smoke_test.py` 的 Phase 0 `print` + `if not good:` → 改成把结果**计入总数与退出码**（N-4：原先失败只打印不计分，导致"工具彻底不可用"时冒烟仍报 61/61 通过）。
- `README.md` / `SKILL.md`：纯文档。

### 3. ⚠️ 唯一一条**已知的行为契约破坏**

`wait_route_stable` 的 `ok` **不再恒为 `true`**（原版读不到路由时返回 `ok=true, route=""`，调用方会据此判断"路由稳定且为空"）。
这是有意为之、且已在 SKILL.md C 节写明。**如果将来有外部调用方依赖 `ok===true`，这是唯一需要留意的兼容性缺口。**

## 四、唯一一处非预期改动：`package-lock.json` 的一行

```
原版 369: "resolved": "https://registry.npmjs.org/frida/-/frida-16.6.6.tgz",
现在 369: "resolved": "https://registry.npmmirror.com/frida/-/frida-16.6.6.tgz",
```

- **来源**：跑过 npm 安装（本机 npm 配了淘宝镜像），npm 把解析地址写回了 lock。不是人改的。
- **风险**：**低**。同一项的 `integrity`（sha512）**逐字节未变** —— 说明包内容校验仍然有效，不构成供应链风险，只是"从哪下载"变了。
- **建议**：**保留，不回滚**。理由：① 回滚后下次 `01-安装依赖.bat` 会被 npm 再写回去，无意义；② 本机能否直连 `registry.npmjs.org` 未知，而这个镜像地址很可能正是当初能装上的那个。若要发布干净包，在打包前单独把它改回即可。
