# WMP-pentest-automation 项目全景理解

> 编写时间：2026-09-22
> 目的：在继续改进前，建立一份可复盘的完整项目认知基线。
> 所有数据均为**实测核查**（读码 + 运行时验证），非文档转述。

---

## 1. 一句话定位

一套面向 **Windows 微信小程序** 的本地动态安全评估工具链：用 Frida 注入把微信小程序"打开调试门"，再把微信私有的 protobuf 调试协议翻译成标准 CDP，最后封装成 **69 个 MCP 工具** 供 AI Agent 按 `SKILL.md` 流程自动化驱动。

**不是** GUI 工具。GUI（`e0e1-wx/main.py`）是上游遗留，本项目**不使用**，且会与无头引擎抢 9421 / 62000 端口。

---

## 2. 三组件职责与边界

| 组件 | 语言/运行时 | 职责 | 产出 |
|------|------------|------|------|
| `偏移提取工具/` | Python 3.10+ | 静态解析 `flue.dll`，提取 Frida hook 所需的结构偏移 | `addresses.{ver}.json`（**两份**，须一致） |
| `WMPFDebugger/` | TypeScript + Node 20 + Frida 16.6.6 | 注入 `WeChatAppEx.exe`，改写三处内存（scene / websocket url / remote debug mode） | 小程序回连 9421；对外暴露 62000 CDP |
| `e0e1-wx/` | Python 3.10+ | 私有 protobuf ⇄ 标准 CDP 转译；MCP 工具链 | HTTP MCP 服务（49999） |

### 关键设计：两套并行实现

`e0e1-wx/package/` 里存在**两条功能重叠的 CDP 链路**：

- **MCP 侧**（`mcp_control/`）：headless、无 Qt 依赖、面向 Agent —— 本项目的实际出口
- **GUI 侧**（`devtools/`、`applet_routes/`、`miniapp_jump/`、`monitor/`）：依赖 PySide6、面向人工操作

`mcp_control` 只被 `ui/main_window.py` 与 `ui/mcp_dialog.py` 引用。**两套各自实现 CDP 连接、Hook 注入、请求归一化**，是重复代码与技术债的主要来源。

## 5. 偏移适配（最易踩坑的一环）

本机实测环境：微信 `Weixin.exe` 4.1.15.8，WMPF **25707**，`flue.dll` 位于
`%APPDATA%\Tencent\xwechat\xplugin\Plugins\RadiumWMPF\25707\extracted\runtime\flue.dll`

### modern vs legacy 是**致命分野**

| 布局 | 判定锚点（全中即 modern） | JSON 结构 |
|------|--------------------------|-----------|
| legacy（≤25xxx 早期） | — | `LoadStartHookOffset` + `CDPFilterHookOffset` + `SceneOffsets`(6) |
| modern（25xxx 中后期起） | `devtools_message_filter_applet_webview.cc`、`CastToJson`、` request.url=` 等 | 再加 `CastToJsonHookOffset` + `MiniAppConfigStructOffsets` |

**把 modern 版本喂 legacy JSON → hook 走 legacy 分支 → 崩。** 且 legacy 提取器会输出一个**格式合法但内容错误**的 `SceneOffsets`，不会报错。

`sync_latest_wmpf_offsets.py` 已把默认引擎换成 modern 检测器，规避了这个坑。

## 9. 核心设计约定（踩坑清单）

### 9.1 FastMCP 签名即契约 —— 本项目最高频 bug 源

FastMCP 由 **函数签名自动生成 `inputSchema`**。实现层（`runtime_session.py`）支持某参数、但 `@tool` 函数签名没声明 → schema 带 `additionalProperties: false` → **调用直接拒收**，报参数校验错误。

已复现两次（`excludeStatic`、`compact`/`excludeTelemetry`/`maxLength`）。**改实现层必须同步改签名层。**

### 9.2 `bool(kwargs.get("x", True))` 陷阱

这是「**键不存在**才取默认值」。显式传 `None` → `bool(None) == False` → **顶掉默认值**。

所以包装层透传必须过滤 `None`：

```python
**{k: v for k, v in extra.items() if v is not None}   # 正确
**{k: v for k, v in extra.items() if v}               # 错误：会丢掉 False
```

### 9.3 双上下文边界

| 工具 | 上下文 | 可用 |
|------|--------|------|
| `runtime_eval` | page-frame | `window.__routeNavigator`；**无** `getCurrentPages` / `wx` |
| `runtime_eval_appservice` | appservice | `getCurrentPages`、`wx.*` |

### 9.4 WMPF JS 引擎怪癖

appservice 里**箭头函数体含 `try` 会 `SyntaxError: Unexpected token ')'`**，必须写 `(function(){ ... })()`。

### 9.5 其他

- `getCurrentPages()` 有 **4–7s 读取延迟**：导航回调 OK ≠ 页面栈已更新
- Goji 原生渲染下 page-frame **无 DOM**，`list_interactive_elements` 返回 0 属正常
- `SKILL_GATE`：未读 skill 时拦首次业务工具调用，把 SKILL.md 开篇塞进返回
